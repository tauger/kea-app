# kea-app

Public landing + support + privacy site for [Kea](https://github.com/tauger/kea), an AI-native email client for macOS.

This repo's `main` branch is published as a GitHub Pages site at:
**https://tauger.github.io/kea-app/**

- `index.md` — landing / support page
- `privacy.md` — privacy policy (linked from App Store listing)
- `_config.yml` — Jekyll config

Pages auto-rebuild on every push to `main`.
